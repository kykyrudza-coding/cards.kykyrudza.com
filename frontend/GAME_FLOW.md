# Blackjack: поточний flow

## Екран і керування

Верхня панель має рамку: раунд, з'єднання, баланс, фактична ставка, етап, звук,
налаштування та вихід. На ПК action bar розташований ліворуч. Клавіші:
H — Hit, S — Stand, D — Double, P — Split. На телефоні кнопки залишаються
великими; у landscape вони знаходяться ліворуч. Зелений стіл збільшено.

## Від сервера до анімації

`stores/match.ts` одразу приймає авторитетний серверний snapshot, відкидає старші
версії у зворотному порядку та блокує повторну локальну дію під час запиту.
`useGamePresentation.ts` і `GameAnimationController.ts` тримають окрему копію для
відображення. Рахунок, виплати, дозволені дії та фішки визначає сервер.

`AnimationQueue.ts` послідовно виконує GSAP timelines. AbortController скасовує
чергу при resize, background, reconnect та unmount. Повторний snapshot тієї самої
версії не програє звук чи роздачу вдруге. Після повернення до вже завершеного
раунду показується актуальний стан без повторної роздачі.

- `CardAnimation.ts`: роздача від видимої колоди, невелика дуга і нахил, приземлення
  зі звуком; flip сорочки через rotateY; Split із вимірюванням старих і нових
  позицій; збір карт до discard із коротким stagger.
- `ChipAnimation.ts`: переміщення фішки до дилера або гравця за серверним результатом.
- `AnimatedChips.vue`: плавне оновлення балансу за 550 мс.
- `PlayingCard.vue`: дві сторони, perspective, backface-visibility, тінь і непрозора
  основа. `cardImages.ts` завантажує та декодує 52 обличчя і сорочку перед роздачею;
  конкретні DOM-зображення також декодуються перед deal/flip.
- `DeckStack.vue`, `GameTable.vue`, `GameStage.vue`, `GameHUD.vue`, `HandView.vue`,
  `DealerArea.vue`, `BetControls.vue`: колода, стіл, HUD, результати та ставки.

Reduced motion і вимкнені card/chip animations зберігають робочу гру без рухів.
Прихована карта не має rank/suit у відповіді сервера або в DOM до reveal.

## Раунд і ставки

Після дилера: 300 мс пауза → inline результат кожної руки та серверний profit →
приблизно 2 секунди показу → збір карт → підтвердження ставки. Round complete modal
видалено. Автоматичного списання нової ставки після таймера більше немає.

Перший раунд запускає Start game зі ставкою лобі. Між раундами кожен активний
гравець підтверджує власну суму. Мінімум 100; 100…1000 із кроком 100,
1500… із кроком 500, у межах балансу. Після підтвердження сума незмінна до роздачі.
Баланс не списується, доки всі учасники з достатніми фішками не підтвердили ставки.

`POST /api/matches/{id}/bet {amount, expected_round}` працює в транзакції з
блокуванням матчу. Останнє підтвердження запускає одну роздачу з індивідуальними
ставками. Ідентичний повтор до роздачі ідемпотентний; застарілий раунд дає 409.
JSON `confirmed_bets` зберігається в існуючому стані; міграція БД не потрібна.
Старий `next-round` не може обійти підтвердження. Відсутній гравець із достатнім
балансом затримує нову роздачу; автоматичного timeout/fold наразі немає.

Split тепер порівнює вартість двох карт: J+K, 10+Q та інші десяткові пари дозволені.
Зберігаються вимоги до черги, достатнього балансу та максимуму двох рук.

## Звук і асети

Раніше ефекти були процедурними WAV, а ігровий екран не мав підключеного
відтворення: збережені налаштування гучності самі по собі не запускали звук.
Процедурні ефекти замінено 12 записаними cues Kenney Casino Audio, CC0.
Є 3 варіанти deal, flip, collect, shuffle, single chip, bet, payout, click, win, lose.
Win/lose — короткі предметні звуки, без музики. OGG + MP3 разом: 175 960 байтів.
Джерела, оригінали та ліцензія: `../assets/ATTRIBUTION.md`.

`audio/GameAudio.ts` використовує Web Audio для готових записів: unlock після
жесту, preload/decode, fallback кодека, master/SFX/voice gain, mute, не більше
чотирьох одночасних ефектів, deal pitch 0.96–1.04, звук у момент приземлення.
Налаштування показують loaded/total і дозволяють перевірити звук. Три українські
тестові TTS-репліки збережено; це окремі прототипні файли, не CC0-записи Kenney.

3D-моделі не інтегровано: поточний шар — DOM + GSAP 2.5D без Three.js.
Перевіреного 3D-набору не відібрано; знайдений Kenney Playing Cards Pack є 2D.

## Перевірка

Backend tests охоплюють індивідуальні ставки, кроки, баланс, phase/participant
authorization, повторення запитів, виключення гравців без фішок і Split J+K / 10+Q.
Playwright перевіряє шість viewport, дії, ставки, realtime, background/resize,
decode/mute та затримане завантаження текстур. Окремий opt-in live тест створює
двох локальних користувачів і грає три раунди через API та Reverb.
Mobile Safari/iOS і фізичне звучання динаміків потребують перевірки на пристрої;
автоматичні браузерні перевірки виконуються в Edge/Chromium.

Остання перевірка: `npm run build` — успішно; `php artisan test --compact` —
98 тестів, 334 assertions; Playwright UI — 19/19; live API/Reverb — 1/1,
три раунди двома користувачами з підтвердженням ставок, Hit/Stand/Double/Split.
Viewport: 1920×1080, 1440×900, 1024×768, 390×844, 430×932, 844×390.

Візуальний стіл побудовано шарами CSS: сукно, кант, шви та м’яке освітлення.
Карти розташовані над компактними профілями гравців; підтверджені ставки мають
окремі місця для фішок. Додаткові чотири UI-перевірки охоплюють Split і результати
за столом із сімома гравцями, зокрема відсутність накладання місць на ПК.
